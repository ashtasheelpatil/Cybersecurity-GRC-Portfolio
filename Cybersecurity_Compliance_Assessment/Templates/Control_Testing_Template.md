# Control Testing Template

## Control
Control ID and requirement.

## Control Owner
Responsible function.

## Test Objective
What the test is intended to establish.

## Population
Define the population from which samples are selected.

## Sample
Record sample size, selection method, and sample identifiers.

## Test Procedure
Describe the steps performed.

## Evidence
List objective evidence reviewed.

## Result
Pass / Partial / Fail.

## Conclusion
State whether the control is suitably designed and effectively implemented.
