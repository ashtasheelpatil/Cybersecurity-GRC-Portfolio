# Information Security Questionnaire

1. Do you maintain an information security policy?
2. Is security governance formally assigned?
3. Do you perform periodic risk assessments?
4. Is MFA implemented for privileged access?
5. Is sensitive data encrypted in transit and at rest?
6. Are security logs monitored?
7. Is vulnerability scanning performed?
8. Are critical vulnerabilities remediated within defined SLAs?
9. Is penetration testing performed?
10. Is employee security awareness conducted?
11. Is access reviewed periodically?
12. Is there a documented incident response plan?
13. Are backups protected and tested?
14. Is business continuity tested?
15. Are subcontractors assessed?
16. Can customers receive relevant security assurance evidence?
