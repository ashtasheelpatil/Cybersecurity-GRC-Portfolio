# Vendor Offboarding Checklist

- [ ] Business owner confirms termination.
- [ ] Contract termination obligations reviewed.
- [ ] Vendor access identified.
- [ ] Access revoked.
- [ ] Credentials/tokens/API keys revoked.
- [ ] Assets returned.
- [ ] Data returned or securely deleted.
- [ ] Backups addressed according to retention requirements.
- [ ] Subcontractor access addressed.
- [ ] Final security confirmation obtained.
- [ ] Vendor inventory updated.
- [ ] Residual risks closed or transferred.
