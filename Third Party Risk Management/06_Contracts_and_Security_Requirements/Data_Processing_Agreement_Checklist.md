# Data Processing Agreement Checklist

- [ ] Parties and roles identified.
- [ ] Processing instructions documented.
- [ ] Data categories defined.
- [ ] Security measures documented.
- [ ] Confidentiality obligations included.
- [ ] Sub-processor requirements included.
- [ ] Data subject assistance addressed.
- [ ] Breach notification obligations addressed.
- [ ] Return/deletion requirements included.
- [ ] Audit/assurance mechanism defined.
