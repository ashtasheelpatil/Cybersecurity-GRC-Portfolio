# Data Privacy Compliance Assessment

## Overview
A practical GRC portfolio project demonstrating a simulated data privacy compliance assessment for **NexaTech Solutions LLC**, a fictional Dubai-based SaaS organisation.

## Objectives
- Assess privacy governance and accountability
- Build a personal-data inventory and ROPA
- Assess lawful basis, purpose limitation and consent
- Assess data-subject rights
- Review security and retention controls
- Assess processors and international transfers
- Perform DPIA and privacy risk assessment
- Map privacy requirements to recognised frameworks
- Identify compliance gaps
- Create risk treatment and remediation plans
- Produce management reporting and continual-improvement metrics

## Framework Context
The project uses the **UAE Personal Data Protection Law (PDPL)** as the primary UAE context, with **GDPR**, **ISO/IEC 27701**, **ISO/IEC 27001**, and the **NIST Privacy Framework** used as assessment references where relevant.

Applicability of any particular law or requirement must be determined from the actual organisation, processing activities, jurisdictions and legal facts.

## Project Lifecycle
Project Initiation → Data Context → Privacy Governance → Data Inventory/ROPA → Lawful Basis → Data Subject Rights → Security/Retention → Third Parties/Transfers → DPIA → Compliance Assessment → Risk/Remediation → Management Reporting → Continual Improvement

## Key Deliverables
Project Charter • Data Processing Inventory • ROPA • Lawful Basis Assessment • Consent Assessment • DSAR Register • Security Assessment • Retention Assessment • Processor Assessment • Transfer Assessment • DPIA • Privacy Risk Register • Control Mapping • Gap Assessment • Remediation Plan • Management Report • KPI/KRI Register

## Portfolio Disclaimer
This is a **fictional portfolio simulation** for demonstrating GRC/privacy assessment skills. It is not a legal opinion, certification, independent audit, or representation of an actual organisation.
