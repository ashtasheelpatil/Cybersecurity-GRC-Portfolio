# Security Incident & Compliance Response

A portfolio-ready simulated project demonstrating an end-to-end security incident lifecycle: detection, triage, classification, containment, investigation, compliance assessment, notification decision, recovery, risk treatment, corrective action, audit evidence, management review and continual improvement.

## Central Case Study
A simulated phishing-led credential compromise develops into unauthorized cloud access, sensitive-data exposure and ransomware disruption.

## Framework Alignment
- ISO/IEC 27001
- ISO/IEC 27002
- NIST incident-response guidance
- NIST Cybersecurity Framework
- General privacy/data-breach compliance concepts

## Important
All organizations, incidents, evidence and records are simulated for training and portfolio purposes. Actual legal/regulatory notification decisions require jurisdiction-specific legal/privacy review.
