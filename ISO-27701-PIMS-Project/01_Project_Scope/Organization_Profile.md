# Organization Profile — FinSecure Technologies
Fictional educational scenario. FinSecure provides a cloud-based financial workflow platform to business customers.

**Functions:** customer onboarding, payment-related workflows, support, recruitment, HR/payroll, vendor management, engineering, IT/security, legal/compliance, privacy governance.

**Data subjects:** customers and authorized users; payment-related individuals; support requesters; applicants; employees; vendor contacts.

**Illustrative data:** identity/contact details, account IDs, transaction references/statuses, support text/attachments, CVs, payroll data, vendor correspondence, user IDs and security logs.  

**Systems:** illustrative CRM, cloud application/database, ticketing, HR/recruitment, identity provider, logging and vendor services. Actual systems, providers, locations, and transfers are unknown.

FinSecure may be controller for its own CRM/HR activities and processor for some client-directed services; determine role activity-by-activity from facts and contracts. No real personal data is included.
