# ISO/IEC 27701 PIMS Portfolio Project
**Scenario:** FinSecure Technologies, a fictional SaaS/FinTech organization.  


This project demonstrates a proposed Privacy Information Management System (PIMS), including scope, interested parties, objectives, data inventory, RoPA, retention, privacy risk, treatment, policy/procedures, control mapping, assurance, evidence tracking.

## Structure
- `01_Project_Scope/` — profile, scope, interested parties, objectives
- `02_Data_Governance/` — data inventory, RoPA, retention matrix, data flow, rights procedure
- `03_Privacy_Risk/` — methodology, assessment, treatment plan
- `04_Policies_and_Procedures/` — privacy policy and procedures
- `05_Controls_and_Assurance/` — control mapping, assessment, audit checklist, CAPA
- `06_Governance_and_Review/` — roles, management review, improvement log
- `07_Evidence_Register/` — evidence register


## Traceability example
`DI-001` → `ROPA-001` → `PR-001` → `RTP-001` → `EV-001`.

**Important:** All data, scores, owners, targets, retention rules, and controls are illustrative. No controls have been independently tested. This is not certification, legal advice, or proof of compliance. Validate actual systems, contracts, laws, transfers, and current ISO requirements before operational use. ISO standards are copyrighted; this project uses original examples and high-level mappings, not reproduced standard text.
