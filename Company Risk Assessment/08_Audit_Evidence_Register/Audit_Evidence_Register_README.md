# Audit Evidence Register

## Purpose
The Audit Evidence Register demonstrates how an ISO/IEC 27001 internal auditor can connect a control requirement to objective evidence, an audit result, a finding, and corrective action.

## Audit Chain
**Control → Audit Objective → Evidence Required → Evidence Status → Auditor Result → Finding → Corrective Action → Follow-up**

## Contents
The register contains 15 simulated evidence review items covering:
- Access control
- Authentication information
- Source code access
- Configuration management
- Technical vulnerability management
- Information backup
- Logging
- Monitoring
- Remote working
- Change management
- Security awareness and training
- Protection of records
- Secure coding
- Environment separation
- Privileged access rights

## Finding Approach
The portfolio demonstrates:
- Pass
- Pass with Observation
- Minor Nonconformity
- Major Nonconformity

The findings are intentionally simulated to demonstrate audit judgment and corrective-action tracking.

## Auditor Lesson
A good auditor does not simply ask whether a policy exists. The auditor seeks objective evidence that the requirement is implemented and operating effectively.

## Important
All evidence, audit results, and findings are simulated for portfolio purposes. They must not be represented as actual evidence or audit conclusions from a real organization.
