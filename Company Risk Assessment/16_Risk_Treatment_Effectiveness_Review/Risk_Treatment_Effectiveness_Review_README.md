# File 16 — Risk Treatment Effectiveness Review

## Purpose
This working paper evaluates whether implemented risk treatments are operating effectively and whether residual risk is within the organization's approved risk-acceptance threshold.

## Core methodology
**Risk → Treatment → Implementation Evidence → Effectiveness Test → Residual Risk → Acceptance Decision → Follow-up**

## Workbook sheets
1. **Effectiveness Review** — 11 simulated risks with pre/post risk scores and treatment effectiveness.
2. **Risk Scoring** — example 5x5 likelihood/impact scoring guidance.
3. **Review Summary** — management-level summary.
4. **Instructions** — how to conduct the review.

## Important Lead Auditor point
Implementation is not the same as effectiveness. An auditor should look for objective evidence that a treatment operates as intended and actually reduces risk.

## Current simulated review
- Effective: 8 treatments
- Partially Effective: 3 treatments
- Not Effective: 0
- Priority follow-up: cloud configuration exceptions, backup restoration testing, and logging/monitoring review evidence.
