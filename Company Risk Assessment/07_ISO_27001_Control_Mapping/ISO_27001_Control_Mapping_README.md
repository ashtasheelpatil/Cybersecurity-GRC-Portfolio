# ISO/IEC 27001 Control Mapping

## Purpose
This file maps the risks and treatment actions from the portfolio Risk Register to relevant **ISO/IEC 27001:2022 Annex A controls**.

## What This Demonstrates
The mapping demonstrates a practical GRC traceability chain:

**Asset → Risk → Treatment → ISO Control → Evidence**

## Mapped Controls
The initial mapping includes controls covering:
- Access control
- Authentication information
- Access to source code
- Configuration management
- Privileged access rights
- Secure coding
- Technical vulnerability management
- Identity management
- Remote working
- Protection against malware
- Information backup
- Logging
- Monitoring activities
- Separation of development, test and production environments
- Change management
- Security awareness and training
- Protection of records

## Important ISO 27001 Note
ISO/IEC 27001 does not require every Annex A control to be implemented automatically. The organization determines applicable controls through its risk treatment process and documents the result in the **Statement of Applicability (SoA)**.

Therefore, this mapping is a portfolio demonstration and must not be presented as an actual certification conclusion.

## Auditor Perspective
An auditor would typically look for:
- Defined requirements
- Assigned ownership
- Implementation evidence
- Operating records
- Review and monitoring
- Evidence of effectiveness
- Consistency with the risk assessment and SoA

## Status
All controls are marked **Planned** because this portfolio has not performed a real implementation audit.
