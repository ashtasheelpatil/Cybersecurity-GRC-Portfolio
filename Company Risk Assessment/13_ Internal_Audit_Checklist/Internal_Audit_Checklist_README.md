# File 13 — Internal Audit Checklist

## Purpose
This is the detailed auditor working paper used during the simulated ISO/IEC 27001 internal audit.

## Core traceability
**Requirement / Control → Audit Question → Expected Evidence → Sample → Objective Evidence → Result → Finding → Corrective Action**

## Workbook sheets
1. **Audit Checklist** — 35 audit tests covering ISO/IEC 27001 clauses and selected Annex A controls.
2. **Finding Log** — working register for observations and nonconformities.
3. **Evidence Index** — evidence tracking and traceability.
4. **Auditor Guide** — practical instructions for completing the working paper.

## How to use
1. Start with the audit plan.
2. For each check, identify the applicable criterion.
3. Interview the process owner and inspect objective evidence.
4. Record the actual evidence in the checklist.
5. Record the sample/population tested.
6. Select the result only after evaluating evidence.
7. If there is a gap, create a Finding ID and complete the Finding Log.
8. Link significant findings to the Corrective Action Register.
9. Verify corrective actions before closing findings.

## Finding classifications
- **Conforming:** Evidence demonstrates the criterion is met.
- **Observation:** Improvement opportunity without sufficient evidence of a nonconformity.
- **Minor Nonconformity:** Limited failure against a requirement/control that does not represent a systemic breakdown.
- **Major Nonconformity:** Significant/systemic failure or absence/breakdown of a required process/control, subject to the applicable audit criteria and certification body's rules.

## Portfolio limitation
All organization names, dates, evidence, samples and results are simulated for portfolio purposes.
