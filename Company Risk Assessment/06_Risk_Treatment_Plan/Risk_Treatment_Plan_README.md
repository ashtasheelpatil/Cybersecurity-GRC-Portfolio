# Risk Treatment Plan

## Purpose
The Risk Treatment Plan converts identified risks into concrete remediation actions, assigns ownership, defines target dates, and establishes completion evidence.

## Source
The treatment actions are derived from the 12 simulated risks in `Risk_Register.xlsx`.

## Treatment Approach
The current portfolio assumes **Mitigate** for all 12 identified risks. This is intentional for demonstration: each risk has a practical control improvement that can be tracked to closure.

## Fields Demonstrated
- Treatment ID
- Risk ID and Asset ID
- Risk description
- Current residual risk
- Treatment decision
- Treatment action
- Control / measure to implement
- Risk owner
- Action owner
- Priority
- Target date
- Status
- Expected residual likelihood and impact
- Expected residual score/rating
- Evidence / completion criteria

## GRC Value
This file demonstrates that risk assessment does not stop at identifying a risk. A GRC practitioner should translate risks into accountable actions that can be monitored, evidenced, and reported to management.

## Important
All owners, dates, scores, and actions are simulated for the portfolio. In a real organization they would be agreed with responsible business and control owners.
