# File 15 — Audit Finding Register

## Purpose
A controlled register for audit observations and nonconformities, linking each finding from audit criteria and objective evidence through corrective action and effectiveness verification.

## Workbook sheets
1. **Finding Register** — master register containing four simulated findings.
2. **Traceability** — links findings to audit checks, risks, treatment actions, corrective actions and the audit report.
3. **Follow-up Log** — effectiveness verification and closure working paper.
4. **Summary Dashboard** — management-level finding status.
5. **Instructions** — how an auditor should use the register.

## Simulated findings
- F-001: Major Nonconformity — Privileged Access / MFA
- F-002: Minor Nonconformity — Backup & Recovery
- F-003: Minor Nonconformity — Logging & Monitoring
- F-004: Minor Nonconformity — Secure Development

## Key audit principle
A corrective action is not the same as effective closure. The auditor should verify implementation and then evaluate effectiveness before recommending closure.
