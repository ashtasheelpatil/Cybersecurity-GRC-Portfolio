# Project Charter

## Project Title

Company Information Security Risk Assessment

## Organization

ABC Cloud Technologies Ltd.

## Project Type

Information Security / Cybersecurity GRC Risk Assessment

## Project Objective

The objective of this project is to identify, analyze, evaluate, and treat information security risks affecting ABC Cloud Technologies Ltd.

The assessment follows a risk-based approach aligned with the principles of ISO/IEC 27001:2022 and relevant security control concepts from ISO/IEC 27002:2022.

## Business Context

ABC Cloud Technologies Ltd. is a fictional SaaS organization with approximately 120 employees.

The organization provides cloud-based business software and processes customer, employee, financial, and business information.

The company operates primarily using cloud-based services and supports remote working.

## Assessment Objectives

The assessment aims to:

1. Identify critical information assets.
2. Identify relevant threats and vulnerabilities.
3. Assess information security risks.
4. Evaluate existing security controls.
5. Determine residual risk.
6. Develop risk treatment recommendations.
7. Map relevant risks to ISO/IEC 27001 controls.
8. Define appropriate audit evidence.
9. Present key findings to management.

## Scope

The assessment covers:

- Information assets
- Cloud infrastructure
- End-user devices
- Identity and access management
- Business applications
- Data protection
- Remote working
- Third-party services
- Security monitoring
- Backup and recovery
- Incident management

## Out of Scope

The following activities are outside the scope of this assessment:

- Penetration testing
- Source-code security testing
- Physical penetration testing
- Detailed network penetration testing
- Forensic investigation
- Actual exploitation of vulnerabilities

## Assessment Approach

The assessment follows these stages:

1. Establish context
2. Identify assets
3. Identify threats and vulnerabilities
4. Identify existing controls
5. Assess likelihood
6. Assess impact
7. Determine inherent risk
8. Determine residual risk
9. Develop treatment actions
10. Map risks to relevant ISO controls
11. Identify required evidence
12. Report findings

## Risk Assessment Method

A 5 × 5 qualitative risk matrix will be used.

Likelihood and impact will each be rated from 1 to 5.

Risk Score = Likelihood × Impact

## Risk Treatment Options

The following treatment options will be considered:

- Mitigate
- Avoid
- Transfer
- Accept

## Key Stakeholders

| Stakeholder | Responsibility |
|---|---|
| Executive Management | Risk ownership and approval |
| IT Manager | IT security implementation |
| CISO / Security Lead | Security governance |
| HR Manager | Personnel-related controls |
| Legal / Compliance | Regulatory and contractual requirements |
| System Owners | Asset and system protection |
| Employees | Compliance with security requirements |
