# File 18 — ISMS Continual Improvement Register

## Purpose
Centralize continual-improvement opportunities and actions arising from internal audit findings, risk-treatment effectiveness reviews, management review decisions, KPI performance and other ISMS inputs.

## Workbook sheets
1. **Improvement Register** — master register with 10 simulated improvement actions.
2. **Improvement Dashboard** — management summary.
3. **Source Mapping** — traces each improvement to its originating project document.
4. **Verification Log** — implementation and effectiveness/benefit verification.
5. **Instructions** — practical workflow for using the register.

## Simulated improvement actions
- CI-001: Privileged Access / MFA assurance
- CI-002: Critical-workload restore testing
- CI-003: Logging and monitoring QA
- CI-004: Secure-development evidence
- CI-005: Cloud configuration compliance
- CI-006: Backup/recovery assurance
- CI-007: Security-monitoring effectiveness
- CI-008: ISMS KPI reporting
- CI-009: Security training completion
- CI-010: Centralized improvement governance

## Key Lead Auditor point
Continual improvement should be traceable:
**Input → Improvement Opportunity → Action → Owner → Evidence → Effectiveness/Benefit Verification → Closure**

Implementation alone does not prove improvement effectiveness.
