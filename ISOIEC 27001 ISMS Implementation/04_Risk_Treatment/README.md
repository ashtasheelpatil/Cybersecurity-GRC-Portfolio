# Folder 04 — Risk Treatment

Converts assessed risks into treatment actions.

Files:
- Risk_Treatment_Plan.xlsx — treatment actions, controls, owners, dates, residual risk and evidence criteria.
- Risk_Treatment_Report.pdf — management-level treatment summary.

Traceability:
Risk Register → Treatment Decision → Selected Control(s) → Owner → Evidence → Residual Risk → Acceptance

This is a simulated portfolio project and is not evidence of certification.
