# Folder 08 — Operational Records & Evidence

This folder demonstrates the operational records that can support an ISO/IEC 27001 ISMS audit.

## Evidence included
1. Asset Register
2. Access Review Record
3. Security Awareness Training Record
4. Supplier Security Assessment
5. Vulnerability Register
6. Backup & Restore Test Record
7. Incident Register
8. Change Management Register
9. Security Monitoring Review
10. Joiner/Mover/Leaver Record
11. Master Evidence Index
12. Evidence Guide

## Traceability
Control → Procedure → Operational Activity → Record → Audit Evidence

## Important
All records are explicitly simulated portfolio evidence. They should never be presented as genuine records from a real organization.
