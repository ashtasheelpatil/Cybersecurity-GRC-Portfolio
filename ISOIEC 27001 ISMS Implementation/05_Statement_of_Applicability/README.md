# Folder 05 — Statement of Applicability

This folder contains the simulated ISO/IEC 27001:2022 Statement of Applicability.

Files:
- Statement_of_Applicability.xlsx — control-by-control applicability, justification, status and evidence.
- SoA_Implementation_Guide.pdf — explains the purpose, logic, traceability and auditor checks.
- README.md — portfolio documentation.

Important:
The SoA is derived from the simulated company's context and risk treatment. It is not a certification claim and should be validated against the licensed ISO/IEC 27001:2022 standard and actual organizational evidence in a real implementation.
