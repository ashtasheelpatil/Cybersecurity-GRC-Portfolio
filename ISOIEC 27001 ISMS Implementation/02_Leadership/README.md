# Folder 02 — Leadership

This folder establishes leadership direction, accountability and measurable information-security objectives.

Files:
- Information_Security_Policy.pdf
- Roles_and_Responsibilities.xlsx
- Information_Security_Objectives.xlsx

Auditor focus:
1. Is an appropriate information-security policy established and supported by management?
2. Are responsibilities and authorities assigned?
3. Are objectives measurable, monitored and reviewed?
4. Is information security treated as an organizational governance responsibility rather than only an IT function?

This is a simulated portfolio project and is not evidence of certification.
