# Folder 03 — Risk Assessment

Files:
- Risk_Assessment_Methodology.pdf
- Risk_Criteria.pdf
- Risk_Register.xlsx
- Risk_Assessment_Report.pdf

Auditor traceability: Context → Risk criteria → Risk identification → Analysis → Evaluation → Treatment → Residual risk.

This is a simulated portfolio project and is not evidence of certification.
