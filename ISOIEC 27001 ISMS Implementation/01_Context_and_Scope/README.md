# Folder 01 — Context and Scope

This folder establishes the foundation of the simulated ISO/IEC 27001:2022 ISMS.

## Files
1. Organization_Context.pdf — identifies internal/external issues and organizational context.
2. Interested_Parties_Register.xlsx — identifies relevant interested parties, expectations and security relevance.
3. ISMS_Scope.pdf — defines what the ISMS covers.
4. ISMS_Boundaries.pdf — documents organizational, physical, technological, information and supplier boundaries.

## Lead Auditor perspective
An auditor should be able to understand:
- what the organization does;
- what internal/external issues affect the ISMS;
- which interested parties are relevant;
- what requirements matter;
- where the ISMS starts and ends; and
- how external interfaces and dependencies are addressed.

This is a simulated portfolio project, not evidence of certification.
